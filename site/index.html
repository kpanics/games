Cursed Recode

Клиент и движок. Дистрибутив — на GitHub: один подписанный манифест, файлы по SHA-256, ассеты Mojang. Лоадер проверяет каждую цифру перед запуском.

Скачать для Windows Запуск на Linux GitHub

Windows: recode_loader.exe (≈11 МБ) — дальше сам скачает игру и запустит её.
Linux: нативное окно лоадера, игра идёт под Wine.

Что это

Лоадер

На Windows — recode_loader.exe. На Linux — своё нативное окно (вкладки, новости, аккаунты) без единого Win32-вызова. Один и тот же протокол дистрибутива.

Движок

Vulkan, свой рендер и интерфейс. На Linux проводится к драйверу через winevulkan — движок не портирован и не должен был: он работает как есть.

Аккаунты

Регистрация и вход — через API cursedclient.xyz (сайт и форум там же). Вошедший логин становится именем игрока. Без входа игрок — «Player».

Три способа запуска

Пакет для CachyOS/Arch, сборка из исходников или готовый набор из CI.

Linux (CachyOS)

Игра — Windows-бинарни и идёт под Wine; всё остальное (окно, синк, запуск) — нативное. Лоадер сам кладёт игру на «диск C:» префикса, передаёт хосту абсолютные C:\-пути и копирует VC-рантаймы рядом с бинарями. Нужны пакеты wine, curl, freetype2 и видеокарта с Vulkan.

Пакетом

git clone https://github.com/kpanics/games.git
cd games/packaging
makepkg -si
cursed-recode

Из исходников

git clone https://github.com/kpanics/games.git
cd games/linux-loader
cargo build --release
./target/release/cursed-recode-gui

Готовым набором из CI

Артефакт cursed-recode-linux любого зелёного прогона: распаковать и запустить ./cursed-recode.

Подробности и диагностика — docs/CACHYOS.md.

Как устроено

Подпись

Манифест start.json подписан ed25519; лоадер не примет билд, чья подпись или чей хоть один хеш не сошёлся.

Файлы

Каждый файл билда лежит в релизе-складе как object-<sha256> и качается по своему хешу; ассеты — с CDN Mojang по SHA-1, как у самой игры.

Сборка

CI собирает всё сам: мод, движок, лоадер — и публикует два релиза: чистую витрину dist и технический склад dist-objects.
