# cursed-api

API Cursed (cursedclient.xyz): аккаунты, маркет, форум. Rust (axum + SQLite).

Описание API — [docs/API.md](docs/API.md).

## Сборка

`cargo build --release` (бинарник `cursed-api`; deploy-файлы сервиса — в `deploy/`)
